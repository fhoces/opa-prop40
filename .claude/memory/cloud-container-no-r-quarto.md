The cloud container for this repo has Python 3, Node 22, pandoc and a Playwright Chromium, but
no R and no Quarto (checked 2026-10-14). Playwright is at
`/opt/node-tools/node_modules/playwright` and loads with CommonJS `require`, not an ESM import
of the path. `PLAYWRIGHT_BROWSERS_PATH` is preset.

**Why:** the site's reports and materials pages are Quarto, the decks are xaringan, the root
page and the comparison explorer are generated by `comparison/R/site.R`, and `grid.js` files
come from the R pipelines. None of that can be rebuilt in the cloud.

**How to apply:** edit `.qmd`, `.Rmd` and the two comparison templates at the source and leave
rendered html alone. For `index.html` and `comparison/site/explorer/index.html`, make the
identical edit in the template and the generated page, keeping filled token values, so the
author's `Rscript comparison/run.R` reproduces them byte for byte. Run
`python3 .claude/skills/opa-review-loop/tools/needs_render.py <start commit>` to list the local
rebuild commands, and say in the report that the comparison and RJKDC test suites fail on the
committed tree until the author rebuilds. Screenshots and rendered text of JS-filled pages come
from `.claude/skills/opa-review-loop/tools/screenshot.cjs` (`--text` prints innerText).
